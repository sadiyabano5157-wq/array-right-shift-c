A simple C program that performs right shift / element rearrangement in an array using temporary variable and loops.


# Array Element Shift Program (C)

## 📌 Description
This program demonstrates basic array manipulation by shifting elements and rearranging values using a temporary variable.

## 🚀 Working
- An array of 5 elements is initialized
- One element is stored in a temporary variable
- Elements are shifted
- The stored value is placed at the end
- Final array is printed

## 📥 Input (Initial Array)
10 20 40 30 50

## 📤 Output Example
10 20 40 50 30


## 🛠️ Concepts Used
- Arrays
- Loops
- Swapping / shifting logic
